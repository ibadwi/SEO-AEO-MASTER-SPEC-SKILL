- Fact-checked against primary sources (Google Search Central, Merchant Center, schema.org, crawler owners' docs, framework docs); ~150 corrections in both languages. · تدقيق الحقائق مقابل المصادر الرسمية (~150 تصحيحاً باللغتين).
- Added **audit mode** to §0, **§35 site blueprint** (essential pages, page anatomy, root & well-known files, complete head, HTTP/server settings, platform settings, audit report) and **§36 special cases**. · إضافة وضع التدقيق ومخطط الموقع §35 والحالات الخاصة §36.
- `scripts/seo_audit.py`: gzip sitemaps, empty-sitemap failure, SVG `<title>` ignored, multi-value `X-Robots-Tag`, charset-aware decoding, `ld+json` with parameters, `property="twitter:*"`, RTL description ranges, retired rich-result types reported as Low. · إصلاحات سكربت الفحص.
