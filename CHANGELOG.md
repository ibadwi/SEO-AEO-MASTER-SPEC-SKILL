# Changelog · سجل التغييرات

All notable changes to this spec. Dates are year-month. · كل التغييرات المهمة في هذه المواصفة.

## 1.3 — 2026-11-17
- Completed Google AI-feature eligibility, optional-file/schema clarification and preview-control verification in §22.6. · استكمال أهلية ميزات Google وتوضيح اختيارية الملفات والمخططات وخطوات التحقق من ضوابط المعاينة.
- Corrected the unsupported Search Console generative-AI setting claim in §19 and §35.6; documented Googlebot and page-level controls instead. · تصحيح ادعاء إعداد الذكاء الاصطناعي في Search Console وتوثيق Googlebot وضوابط الصفحة.
- Added direct Google AI-feature, robots and crawler references alongside Bing, Schema.org, W3C and the existing sources in §34.2; updated verification scope/date. · إضافة مراجع Google المباشرة إلى جانب Bing وSchema.org وW3C والمصادر السابقة، وتحديث تاريخ ونطاق التحقق.

## 1.2 — 2026-11 (first public release · أول إصدار عام)
- Fact-checked against primary sources (Google Search Central, Merchant Center, schema.org, crawler owners' docs, framework docs); ~150 corrections in both languages. · تدقيق الحقائق مقابل المصادر الرسمية (~150 تصحيحاً باللغتين).
- Added **audit mode** to §0, **§35 site blueprint** (essential pages, page anatomy, root & well-known files, complete head, HTTP/server settings, platform settings, audit report) and **§36 special cases**. · إضافة وضع التدقيق ومخطط الموقع §35 والحالات الخاصة §36.
- `scripts/seo_audit.py`: gzip sitemaps, empty-sitemap failure, SVG `<title>` ignored, multi-value `X-Robots-Tag`, charset-aware decoding, `ld+json` with parameters, `property="twitter:*"`, RTL description ranges, retired rich-result types reported as Low. · إصلاحات سكربت الفحص.
- Definition of done renumbered to §37. · صار تعريف الإنجاز §37.
